# PolySpire

Мобильная защита ядра. Здесь текущая игра: код с сервера, тесты и сборка. История коммитов до 27 сентября 2026 остаётся в [Roguebullet](https://github.com/SwaTik91/Roguebullet).

Картинки пушек лежат в `art-packed` и сами появляются в `public/` перед запуском и сборкой.

Мобильная защита ядра: автопулемёт в центре, ручной прицел, волны геометрических врагов, роглайк-карты и крит.

## Запуск

```bash
npm install
npm run dev
```

Открой адрес в браузере телефона. Портретная ориентация.

## Управление

- Без пальца пулемёт сам целится в ближайшую цель и крутится на 360°.
- Удерживай палец, чтобы навести вручную. Ручной выстрел наносит больше урона.
- Враги появляются сверху, снизу и с боков.
- В меню «Настройки» можно включить или выключить цифры урона.
